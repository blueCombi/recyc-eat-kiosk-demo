Kiosk Settings

Configure points, redemption rules, rewards, and kiosk operation.

Points per item

Small plastic bottle

Points awarded when a standard plastic bottle is accepted.

Default: 5

Big plastic bottle

Points for larger bottles detected by the kiosk.

Default: 7

Aluminum can

Points awarded for each accepted aluminum can.

Default: 5

Redemption rules

Redemption threshold

Minimum points required on a receipt before a full meal reward can be redeemed.

Matches kiosk meal unlock

Minimum redemption

Lowest points that can be spent in a single redemption.

Maximum redemption

Caps how many points can be redeemed at once.

Reward point costs

Canned meal

Points required to redeem a canned meal. The kiosk uses this same number as the unlock threshold.

Snack pack

Points required for a smaller snack reward.

Saved, but the kiosk currently dispenses canned food only.

Available rewards

Reward items currently offered at this kiosk (one per line).

One reward per line. The kiosk dispenses canned food from this list.

Kiosk operations

Kiosk open for use

When off, the public kiosk shows a temporarily unavailable message.

Auto-print receipts

Print a QR receipt automatically after a successful session.

Stored for when a printer is attached.

Idle session timeout (seconds)

Return to the home screen after this many seconds of inactivity.

Low-stock alert threshold

Flag inventory items when remaining quantity falls to this number or below.
