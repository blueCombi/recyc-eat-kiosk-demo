If a board does not show up

  1. Run the kiosk server on the host, from the project root: npm run print-server.
  2. On the Raspberry Pi, check the boards exist: ls /dev/ttyUSB* /dev/ttyACM*. Two entries means both are plugged in.
  3. If they exist but stay red, it is permissions: sudo usermod -aG dialout $USER, then reboot the Pi.
  4. Close any Serial Monitor. The host gives a serial port to one program at a time.
  5. Use a data USB cable, not a charge-only one, and re-plug. The bridge rescans every few seconds.
  6. Each board must answer WHO with HELLO|BIN or HELLO|VEND, so upload the current sketches.
